# Game com TreeJs

> Exemplo básico de game com TreeJs

## 1️⃣ Criar o projeto

```bash
# Inicia o projeto
npm init -y

# Instala a lib do three.js
npm install three 

# Instala o vite apenas em desenvolvimento
npm i --save-dev vite
```

```bash
# Instala as libs
npm i

```

## 2️⃣ Adiciona o script do Vite no `package.json`

```json
  "scripts": {
    "dev": "vite",
    "build": "vite build",
    "preview": "vite preview"
  },
```

## Teste localmente 3️⃣

```bash
# instala as libs
npm -i

npm run dev
```

## 4️⃣ Gerar o *build* final

```bash
npm run build
```

> O Vite vai criar uma pasta **`dist/`** com todos os arquivos prontos para subir para o site.

## 5️⃣ Testar o *build*

```bash
npm run preview
```
